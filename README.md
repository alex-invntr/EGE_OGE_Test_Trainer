# Тренажёр ЕГЭ и ОГЭ

Тренажёр для подготовки к ОГЭ (9 класс) и ЕГЭ (11 класс) по четырём предметам: **математика, физика, информатика, русский язык**.
Это обычные HTML-страницы: без установки, без сервера и без интернета. Прогресс хранится в браузере.

Тренажёр сделал ИИ (Claude) на основе тренажёра ОГЭ по физике из лекции «Технологии: вчера, сегодня, завтра» (9 инженерный класс).

## Как запустить

**С диска.** Скачайте репозиторий (Code → Download ZIP) или склонируйте его и откройте `index.html` двойным щелчком.
Работает в Chrome, Edge, Firefox и Яндекс Браузере на компьютере и на телефоне.

```bash
git clone https://github.com/alex-invntr/EGE_OGE_Test_Trainer.git
```

**С GitHub Pages.** Все пути в проекте относительные, поэтому сайт работает с GitHub Pages без изменений:
Settings → Pages → Source: Deploy from a branch → `master` / `(root)`.
Адрес будет `https://alex-invntr.github.io/EGE_OGE_Test_Trainer/`.
Пока репозиторий частный, Pages на бесплатном тарифе GitHub недоступен. На платном тарифе сайт Pages открыт всем, даже если репозиторий частный.

Цифры экзаменов взяты из спецификаций ФИПИ на 2027 год. Пока это проекты, итоговые документы могут уточниться.
В ЕГЭ по математике тренажёр готовит к профильному уровню.

Для каждого предмета:

- **Тренировка по теме** — задачи в формате экзамена, три подсказки лесенкой: идея → план → почти решение. Решение открывается только после попытки.
- **Мини-экзамен** — задачи из всех тем на время, без подсказок. Итог по темам и список ошибок для разбора.
- **Повторение ошибок** — ошибка возвращается через 1, 3, 7 и 14 дней, пока не перестанет повторяться.
- **«Спросить ИИ»** — готовый запрос с условием задачи и ответом ученика. ИИ задаёт наводящие вопросы, а не решает за ученика.
- **Самопроверка второй части** — критерии ФИПИ: ученик ставит себе баллы, как эксперт.
- **Задачник** — все задачи с ответами и решениями, можно распечатать.

Типы ответов: число, несколько чисел, выбор одного или нескольких вариантов, соответствие, набор цифр, слово, свободный ответ со сравнением с образцом.

Страница [guide.html](guide.html) — методика «6 шагов» подготовки с ИИ и готовые запросы для всех предметов.

## Как проверены задачи

Задачи оригинальные, в стиле экзаменов. Формат экзаменов взят из спецификаций и демоверсий ФИПИ.
Ни один ответ не взят «на веру»:

- **Пересчёт ответов.** Для каждого банка есть скрипт `tools/check_<экзамен>_<предмет>.py`. Он заново вычисляет ответы по данным условия: формулы физики, правила буравчика и левой руки через векторное произведение, уравнения и производные через sympy, программы по информатике — выполнением кода и перебором. Для русского языка скрипт сверяет ответы с полными верными написаниями слов и расставленными знаками препинания.
- **Прогон в браузере.** Скрипт `tools/trainer_check.js` открывает страницы с диска в Chrome или Edge в фоне. Для каждой задачи он вводит неверный ответ и проверяет, что тот отклонён, затем вводит верный и проверяет, что тот принят. Ещё он прогоняет мини-экзамен, подсказки, повторение ошибок, задачник и запросы к ИИ.

Запуск проверок:

```bash
python tools/check_all.py
```

```bash
npm install --prefix tools puppeteer-core@23.11.1
```

```bash
node tools/trainer_check.js
```

## Устройство проекта

| Путь | Что это |
|---|---|
| `index.html` | главная: выбор экзамена и предмета, прогресс по каждому |
| `trainer.html?b=oge_math` | тренажёр одного банка задач |
| `guide.html` | методика подготовки с ИИ и готовые запросы |
| `css/style.css` | общий стиль |
| `js/common.js` | каталог предметов, хранение прогресса |
| `js/trainer.js` | движок тренажёра |
| `banks/*.js` | банки задач; формат — в [banks/README.md](banks/README.md) |
| `tools/` | скрипты проверки ответов и прогона в браузере |

Чтобы добавить задачу, допишите её в нужный файл `banks/*.js` по формату из `banks/README.md`.
Затем добавьте пересчёт ответа в `tools/check_*.py` и запустите проверки.

## Важно

- Прогресс хранится только в этом браузере на этом компьютере. Очистка данных браузера его стирает.
- Перед экзаменом сверьтесь с актуальной демоверсией и кодификатором на [fipi.ru](https://fipi.ru).
- ИИ ошибается уверенно: его ответы сверяйте с ответами ФИПИ и учебником.
