Как заниматься в тренажёре

Тренажёр готовит к ОГЭ (9 класс) и ЕГЭ (11 класс) по четырём предметам: математика, физика, информатика, русский язык. 313 задач в формате экзаменов, подсказки, разборы, мини-экзамены, повторение ошибок и ИИ-репетитор, который задаёт наводящие вопросы, а не решает за ученика.

Без установки и регистрации: обычные HTML-страницы, работают в браузере на компьютере и на телефоне, в том числе без интернета. Прогресс хранится в браузере ученика.

Тренировка по теме: сначала сам, потом подсказка, потом ИИ

Решение открывается только после попытки. После ошибки появляется первая подсказка, всего их три: идея, план, почти решение.

«Спросить ИИ»: наводящие вопросы вместо готового ответа

Кнопка собирает готовый запрос с условием задачи и ответом ученика. Кнопки в окне сами копируют его и открывают Claude, Gemini или DeepSeek — остаётся вставить запрос. В запросе прямо сказано: не называть ответ, задать один наводящий вопрос и проверить запись по критериям экзамена.

Вторая часть: разбор и самопроверка по критериям ФИПИ

После верного ответа на задачу с развёрнутым решением ученик видит полный разбор и ставит себе баллы по критериям эксперта.

Мини-экзамен и повторение ошибок

Мини-экзамен идёт на время и без подсказок, в нём по задаче из каждой темы. Итог показан по темам. Каждая ошибка попадает в «Повторить ошибки» и возвращается через 1, 3, 7 и 14 дней, пока не перестанет повторяться.

Информатика и русский язык

В задачах по информатике программы и данные показаны с отступами. Ответ может состоять из нескольких чисел. В русском языке есть тексты с пронумерованными предложениями и позициями знаков, изложение и сочинение с образцом и критериями.

Задачник для учителя

Все задачи предмета на одной странице, ответы и решения спрятаны под спойлером. Страницу можно распечатать.

Ещё задания: РешуОГЭ, РешуЕГЭ, КЕГЭ

Когда задачи тренажёра решены без ошибок, новые задания берутся из каталогов РешуОГЭ и РешуЕГЭ: там задания открытого банка ФИПИ по номерам КИМ, с ответами и решениями. По информатике ЕГЭ — ещё КЕГЭ: задания и варианты в компьютерном формате. Под каждой задачей тренажёра есть ссылка на нужный каталог и номер задания.

Как проверены задачи

Задачи оригинальные, в стиле экзаменов: найденные совпадения с открытыми источниками заменены. Ни один ответ не взят «на веру».

  • Пересчёт ответов. Для каждого банка есть скрипт, который заново вычисляет ответы по данным условия: формулы физики, правила буравчика и левой руки через векторное произведение, уравнения и производные через sympy, программы по информатике — выполнением кода и перебором. Для русского языка скрипт сверяет ответы с полными верными написаниями слов и расставленными знаками препинания.
  • Слепое решение. В русском языке норму не пересчитать кодом. Поэтому отдельный ИИ-агент получил задания без ответов, решил их сам, и его ответы сравнили с банком.
  • Прогон в браузере. Для каждой задачи скрипт вводит неверный ответ и проверяет, что тот отклонён, затем вводит верный и проверяет, что тот принят. Ещё он прогоняет мини-экзамен, подсказки, повторение ошибок, задачник и запросы к ИИ.
  • Рисунки. Чертежи и графики сверены с ответами по клеткам и размерам. Для графиков функций скрипт проверки читает точки прямо из рисунка.
  • Проверка на совпадения. Все 313 задач сверены с открытым банком ФИПИ, демоверсиями, РешуОГЭ/РешуЕГЭ, КЕГЭ, задачниками и решебниками. 94 задачи заменены своими: у 36 нашлись совпадения в источниках, у 4 — частичные, ещё 54 «ходовые» задачи с круглыми числами заменены на всякий случай.

Важно

  • Прогресс хранится только в браузере ученика. Очистка данных браузера его стирает.
  • ИИ ошибается уверенно: его ответы сверяйте с ответами ФИПИ и учебником.
  • По условиям сервисов: Claude — только с 18 лет; DeepSeek — до 18 лет с согласия родителей; Gemini — с возраста, когда можно самостоятельно вести аккаунт Google, младше — с разрешения родителей.
  • Тренажёр — независимый учебный проект: он не связан с ФИПИ, РешуОГЭ, РешуЕГЭ, КЕГЭ, Anthropic, Google и DeepSeek; их названия упомянуты только для ссылок.
  • Официальные демоверсии, кодификаторы и открытый банк заданий — на fipi.ru.
