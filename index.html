Как устроен тренажёр

  • Тренировка по теме — задачи в формате экзамена, три подсказки лесенкой: идея → план → почти решение.
  • Мини-экзамен — задачи из всех тем на время, без подсказок; итог по темам и список ошибок.
  • Повторение ошибок — ошибка возвращается через 1, 3, 7 и 14 дней, пока не перестанет повторяться.
  • «Спросить ИИ» — готовый запрос с условием и твоим ответом: ИИ задаёт наводящие вопросы, а не решает за тебя.
  • Самопроверка части 2 — критерии ФИПИ: сам ставишь себе баллы, как эксперт.
  • Задачник — все задачи с ответами и решениями, можно распечатать.

Готовиться с ИИ — правильно

ИИ — тренер, который задаёт вопросы и проверяет, а не решебник. Методика из шести шагов и готовые запросы для всех предметов.

Методика

Ещё задания: РешуОГЭ, РешуЕГЭ, КЕГЭ

Когда задачи тренажёра решены без ошибок, бери новые из каталогов РешуОГЭ и РешуЕГЭ: там задания открытого банка ФИПИ по номерам КИМ, с ответами и решениями. По информатике ЕГЭ — ещё КЕГЭ: задания и варианты в компьютерном формате.

Работает без интернета: index.html запускается двойным щелчком. Прогресс хранится только в этом браузере на этом компьютере. Формат экзаменов — по спецификациям ФИПИ; задачи — оригинальные, в стиле экзамена, каждый ответ проверен независимым скриптом. Официальные демоверсии и открытый банк заданий — на сайте fipi.ru. Исходный код и описание — на GitHub.
