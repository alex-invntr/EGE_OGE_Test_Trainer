# Формат банка задач

Один файл — один экзамен и один предмет: `banks/<exam>_<subject>.js`, например `banks/oge_math.js`.
Файл подключается страницей тренажёра обычным `<script src>`, поэтому он работает и с диска, и с GitHub.

```js
// Банк задач: ОГЭ · математика (9 класс). Формат описан в banks/README.md.
// Объект — строгий JSON: его же читают скрипты проверки из tools/.
var BANKS = BANKS || {};
BANKS["oge_math"] = {
  ...
};

// Для скриптов проверки (Node.js); в браузере эта строка ничего не делает
if (typeof module !== "undefined") {
    module.exports = BANKS["oge_math"];
}
```

Все банки складываются в общий объект `BANKS`, поэтому главная страница может подключить их все сразу.
Ключ — `<exam>_<subject>`, он же имя файла.

**Объект банка — строгий JSON**: двойные кавычки, без комментариев внутри объекта, без висячих запятых.
Скрипты из `tools/` вырезают текст между `BANKS["…"] = ` и последним `};` и разбирают его как JSON.
Образец готового банка — `banks/oge_physics.js`.

## Поля банка

| Поле | Что это |
|---|---|
| `exam` | `"oge"` или `"ege"` |
| `subject` | `"math"`, `"physics"`, `"informatics"`, `"russian"` |
| `examName` | `"ОГЭ"` или `"ЕГЭ"` |
| `subjectName` | название предмета в именительном падеже: `"математика"` |
| `subjectDative` | `"по математике"` — для фраз «тренажёр ОГЭ по математике» |
| `grade` | `"9 класс"` или `"11 класс"` |
| `letter` | одна буква для логотипа: `"М"` |
| `spec` | `{ "tasks", "maxScore", "minutes", "note" }` — число заданий, максимум первичных баллов, минуты и короткое примечание по спецификации ФИПИ |
| `mini` | `{ "tasks": 10, "minutes": 30 }` — размер мини-экзамена в тренажёре |
| `topics` | `{ "key": { "name", "color" } }` — 5–8 тем; порядок ключей = порядок на карте тем |
| `criteria` | `{ "calc": [[балл, "описание"], ...], "text": [[балл, "описание"], ...] }` — критерии самооценки части 2 по ФИПИ этого предмета: `calc` для расчётных/решённых задач, `text` для качественных/текстовых |
| `tasks` | массив задач |

Палитра цветов тем: `#E8590C`, `#E67700`, `#1F5FBF`, `#6741D9`, `#0CA678`, `#D6336C`, `#1098AD`, `#5C940D`.

## Поля задачи

| Поле | Что это |
|---|---|
| `id` | строка, уникальная в банке: буква темы + номер, `"A1"` |
| `topic` | ключ из `topics` |
| `kind` | тип ответа, см. ниже |
| `level` | `"базовый"`, `"повышенный"` или `"высокий"` |
| `format` | подпись, на какое задание КИМ похожа задача: `"задание 9 ОГЭ · уравнение"` |
| `text` | условие: обычный текст без HTML. Допустимы символы `² ³ √ · ≤ ≥ − ≠ × → ∈ ∅ °`, перенос строки `\n` (для нумерованных предложений, списков). Кавычки «ёлочки», тире — |
| `code` | `null` или строка: программа, таблица данных, вывод — показывается под условием моноширинным шрифтом с сохранением отступов |
| `figure` | `null` или строка с inline-SVG (`<svg viewBox='...' ...>…</svg>`, одинарные кавычки внутри, без внешних файлов, ширина рисунка до 420 px) |
| `options` | зависит от `kind` (ниже) |
| `answer` | зависит от `kind` (ниже) |
| `unit` | единица измерения для `number` (`"м/с²"`) или `""` |
| `tol` | относительный допуск для `number`: `0.02` для округлённых, `0` для точных |
| `hints` | ровно 3 подсказки: 1 — идея, правило или формула; 2 — план; 3 — почти решение |
| `solution` | полное решение с ответом, как в разборе репетитора |
| `part2` | `true`, если задача — аналог задания с развёрнутым ответом: после верного ответа показываются критерии оформления |
| `criteria` | необязательное: свой список критериев `[[балл, "описание"], ...]` для этой задачи (например, у задания на 4 балла); без него берётся `criteria.calc` или `criteria.text` банка |

## Типы ответа `kind`

| `kind` | Ввод ученика | `options` | `answer` |
|---|---|---|---|
| `number` | число (можно `0,5`, `1/8`, `2·10^8`) | `null` | число JSON: `3.2` |
| `choice` | один вариант (радиокнопки) | массив строк, 4–5 вариантов, нумеруются 1…n сами | `"3"` — номер варианта |
| `multi` | несколько вариантов (флажки) | массив строк | `"25"` — номера верных по возрастанию |
| `match` | соответствие: выпадающий список к каждой позиции | `{ "left": ["А) …", "Б) …"], "right": ["1) …", "2) …", …] }` | `"321"` — по цифре на каждую позицию `left` |
| `digits` | набор цифр в поле ввода (номера предложений, утверждений, пропусков) | `null` | `"14"` — цифры; сверяется как множество, порядок не важен |
| `numbers` | несколько чисел через пробел (ответы из двух чисел в информатике) | `null` | `"7 155"` — числа через пробел; сравниваются по порядку, каждое число целиком |
| `word` | слово или слова | `null` | строка или массив допустимых строк: `["вследствие", "в следствие"]`; сравнение без учёта регистра, ё = е, пробелы и знаки препинания убираются |
| `text` | свободный ответ (качественная задача, объяснение) | `null` | образец ответа — ученик сравнивает и оценивает себя по `criteria.text` |

В мини-экзамен попадают только задачи с автопроверкой (все, кроме `text`).

## Требования к содержанию

- Задачи в стиле реального экзамена (демоверсии ФИПИ 2026–2027), но оригинальные: не копировать чужие тексты и задачи.
- Каждый ответ проверен независимо: `tools/check_<exam>_<subject>.py` пересчитывает всё, что можно пересчитать кодом.
- Числовые ответы — в тех единицах, что указаны в `unit`; округление — как просит условие.
- Подсказки не называют ответ раньше третьей; решение — полное.
